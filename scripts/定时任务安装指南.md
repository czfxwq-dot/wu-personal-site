# 半百观AI 自动日记定时任务 - 安装指南

## 快速安装（推荐）

### 方法一：使用批处理文件

1. 打开文件资源管理器，进入目录：
   ```
   C:\Users\czfxw\Desktop\claude项目\wu-personal-site\scripts\
   ```

2. 找到 `setup-task.bat` 文件

3. **右键点击** → 选择 **"以管理员身份运行"**

4. 如果成功，会看到：
   ```
   ========================================
   [成功] 定时任务创建成功！
   ========================================
   ```

5. 按任意键关闭窗口

---

### 方法二：手动创建（如果方法一失败）

1. 按 `Win + R`，输入 `taskschd.msc`，回车

2. 在右侧点击 **"创建基本任务"**

3. 填写信息：
   - **名称**：`BanbaiGuan-AutoDiary`
   - **描述**：`每天22:00自动生成半百观AI网站日记`
   - 点击"下一步"

4. 触发器选择：
   - **每天**
   - 时间：**22:00:00**
   - 点击"下一步"

5. 操作选择：
   - **启动程序**
   - 点击"下一步"

6. 程序或脚本：
   - 点击"浏览"
   - 选择：`C:\Users\czfxw\Desktop\claude项目\wu-personal-site\scripts\run-auto-diary.bat`
   - 点击"下一步"

7. 勾选 **"当单击完成时，打开此任务属性的对话框"**
   - 点击"完成"

8. 在任务属性窗口：
   - 勾选 **"使用最高权限运行"**
   - 点击"确定"

---

## 验证任务

1. 打开任务计划程序（`Win + R` → `taskschd.msc`）

2. 在左侧点击 **"任务计划程序库"**

3. 在中间列表中找到 **`BanbaiGuan-AutoDiary`**

4. 查看状态应该是 **"就绪"**

5. 双击可以查看详细信息

## 常见问题

### Q: 任务创建失败？
**A**: 确保以管理员身份运行

### Q: 任务没有按时运行？
**A**: 检查：
- 电脑是否在 22:00 处于开机状态
- 任务计划程序服务是否正常运行
- 查看日志文件 `scripts/auto-diary.log`

### Q: 如何修改运行时间？
**A**: 
1. 打开任务计划程序
2. 双击 `BanbaiGuan-AutoDiary`
3. 切换到"触发器"选项卡
4. 编辑触发器，修改时间

### Q: 如何禁用或删除任务？
**A**: 
- **禁用**：右键任务 → "禁用"
- **删除**：右键任务 → "删除"
