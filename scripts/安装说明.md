# 定时任务安装说明

## 方法一：双击运行（推荐）

1. 打开文件资源管理器
2. 进入目录：`C:\Users\czfxw\Desktop\claude项目\wu-personal-site\scripts\`
3. 找到 `install-task.bat`
4. **右键点击** → **以管理员身份运行**
5. 看到"定时任务创建成功"即可

---

## 方法二：手动创建

如果方法一失败，请按以下步骤手动创建：

1. 按 `Win + R`，输入 `taskschd.msc`，回车
2. 点击右侧"创建基本任务"
3. 填写信息：
   - 名称：`BanbaiGuan-AutoDiary`
   - 描述：`每天22:00自动生成半百观AI网站日记`
4. 触发器：每天 → 22:00:00
5. 操作：启动程序
6. 程序或脚本：浏览选择
   ```
   C:\Users\czfxw\Desktop\claude项目\wu-personal-site\scripts\run-auto-diary.bat
   ```
7. 勾选"使用最高权限运行"
8. 完成

---

## 验证安装

1. 在任务计划程序中找到 `BanbaiGuan-AutoDiary`
2. 状态应显示"就绪"
3. 可以右键 → "运行" 进行测试

---

安装完成后，可以立即测试：
