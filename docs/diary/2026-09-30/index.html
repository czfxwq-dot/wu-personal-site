2026-09-30 82亿美元、30%提速和24条规则——AI不再狂飙，要上路了

160天，周三。

昨天说「AI能力在狂飙，但刹车系统还没装好」。今天四则新闻给了下半句——刹车正在装，路正在修，车要上路了。

DeepSeek发布桌面版安装包、Claude Sonnet 5.5编程能力从10%跳到70%、AMD 82亿美元吞下World Labs、最高法首次发布AI裁判规则24条。四件事指向同一个判断：AI不再只是实验室里的demo，它要正式上路了。

▎DeepSeek Harness v0.2：AI终于有了桌面安装包

DeepSeek发布了Harness v0.2预览版，提供macOS和Windows桌面端安装包。

注意关键词：安装包。不是API，不是网页，是双击就能用的桌面应用。新版本预置了面向日常办公和开发的常用功能，同时新增插件安装与管理页面。

这意味着什么？AI工具正在从「打开浏览器→登录→输入提示→等结果」变成「双击图标→直接干活」。使用路径缩短了一半。

回顾工具进化史：先是命令行，然后是网页，然后是桌面应用，最后是操作系统内置。每一步都在降低使用门槛。DeepSeek这一步，是从「网页」到「桌面」的跨越。

当AI工具像Word和Excel一样放在桌面上，它才真正进入日常工作流。不是「去用AI」，而是「AI就在手边」。

▎Claude Sonnet 5.5：编程能力从10%跳到70%

Anthropic发布Claude Sonnet 5.5，定位Opus 5.5的「快而省」互补款。

最亮眼的数据：Agent编程评测得分从10%跃升至70%。速度提升30%，成本降低30%。专攻范围明确的高频任务——修bug、写文档、处理日常编码。

昨天那篇日记说Sonnet 5.5「一半价格击败Opus但账单暴涨」。今天换个角度看：模型不再追求全能，而是在特定场景做到极致。

10%到70%不是渐进式提升，是量变到质变。这意味着在编程这个具体场景里，Sonnet 5.5从「勉强能用」变成了「可以放心用」。

对开发者来说，这是一个信号：日常编码任务，不需要等最贵的模型了。一个快而省的专用款，可能比全能款更合适。

AI的竞争逻辑正在从「谁更强」变成「谁在特定场景更合适」。不是越大越好，是够用就好。

▎AMD 82亿美元吞下World Labs：从语言到物理世界

AMD以82亿美元收购李飞飞创立的World Labs，交易落地。李飞飞出任AMD首席科学家。

昨天详细分析了这笔交易的逻辑。今天补充一个视角：82亿美元买的不是一家公司，是一张入场券。

World Labs的多模态世界模型Atlas，能从2D图片预测「下一个视角」，生成3D环境。这是让AI从「理解语言」到「理解物理世界」的关键技术。

苏姿丰的算盘很清楚：让World Labs的模型团队直接指导下一代芯片设计。模型团队告诉芯片团队哪里算得慢、哪里数据搬不动。AI下一轮往哪里走，AMD要更早坐到牌桌前。

大模型在语言世界的竞争已经卷到极致。下一个战场是物理世界——机器人、自动驾驶、智能制造，都需要机器「看懂」三维空间。

82亿美元，买的不是技术，是方向。AI从数字走向真实，从屏幕走向物理世界。

▎最高法24条：AI出事，终于有人管了

最高人民法院发布《关于依法审理涉人工智能纠纷案件的意见》，共24条。

这是中国最高法首次就AI发布裁判规则。深度伪造、算法歧视、AI生成内容侵权——这些问题终于有了归责边界。

为什么这件事重要？因为技术落地最大的障碍不是技术本身，是「出了问题谁负责」。

AI生成的内容被用于诈骗，谁担责？算法导致歧视，谁负责？AI Agent越权操作，谁买单？在此之前，没有专门立法，法官只能套用传统法律框架，常常找不到对应条款。

最高法这24条，填补了这个空白。不是全面立法，是在现有法律框架内划定归责边界。务实、及时、有针对性。

对行业来说，这是一个信号：AI可以创新，但必须有人为后果负责。野蛮生长的时代，正式结束。

▎连起来看：AI不再狂飙，要上路了

DeepSeek发布桌面版，AI走进普通用户的桌面。

Claude Sonnet 5.5编程能力从10%跳到70%，AI走进开发者的日常。

AMD 82亿美元收购World Labs，AI从数字世界走进物理世界。

最高法24条规则，AI从野蛮生长走进法律框架。

四件事放在一起是一个判断：AI不再只是实验室里的技术展示，它要正式进入生产、进入生活、进入法律框架。

「上路」意味着什么？意味着工具要好用，不只是强大。意味着规则要清晰，不只是呼吁。意味着责任要明确，不只是事后补救。

从「能做什么」到「该怎么做」，从「谁跑得快」到「谁负责」——这才是产业化的真正起点。

技术足够强，工具足够好用，规则足够清晰——AI终于可以上路了。不是狂飙，是正式出发。

160天。AI在学会走路，也在学会遵守交通规则。
