Original Chinese Content

125天，周四。

前天的日记聊"AI正在走出屏幕"，举了机器人运动会的例子。昨天聊"车企造机器人是能力溢出"。今天，这条线有了一个更上层的判断——AI不只是在走出屏幕，它开始交答卷了。

五件事，五个数字：6B、1180亿、5000亿、8.64秒、1。每一个都在说同一句话：AI迈过了商业化拐点。

▎6B参数打败Claude Opus——效率革命来了

阿里发布并开源Qwen3.8-Flash，千亿总参数，仅激活60亿，性能超越Anthropic的Claude Opus 4.6。

60亿是什么概念？大概是你手机芯片能跑的规模。但它的表现，超过了很多公司花数十亿美元训练的巨型模型。

这意味着什么？前沿智能的成本正在断崖式下降。以前需要一整个数据中心才能跑的能力，现在一块消费级芯片就够了。

我注意到一个趋势：模型竞赛的焦点正在从"参数更大"转向"效率更高"。不是谁更大谁赢，是谁更聪明每块钱谁赢。这是从军备竞赛到效率竞赛的转变。

▎1180亿美元——黄仁勋说变现时代来了

英伟达2027财年半年报，归母净利润1180.1亿美元，同比增长161.1%。

黄仁勋在财报会上明确说：AI已正式迈过历史性拐点，正从小规模试验转向大规模商业化变现。

1180亿美元是什么概念？折合人民币约8500亿，半年。这已经不是"AI有商业前景"了，这是"AI已经在赚大钱"。

而且这些钱不是来自互联网公司的研发预算——而是来自全球企业的真实采购。工厂在买GPU，医院在买GPU，银行在买GPU。AI不再只是实验室里的技术，它正在变成基础设施。

▎5000亿估值——DeepSeek的7个月

DeepSeek前七个月营收约4.75亿元，第二轮融资估值5000亿元（约740亿美元）。

成立不到三年，估值飙升到5000亿。这个速度本身就说明了一件事：资本市场对AI商业化的信心已经到了一个新阶段。

但更值得注意的是那个营收数字——4.75亿元。虽然不算大，但它是真实的企业客户在付费使用，不是免费试用的虚假繁荣。从"有人用"到"有人付费"，这一步比从0到1更难。

▎8.64秒——机器人三天破两次纪录

第二届世界人形机器人运动会百米决赛，天骄队跑出8.64秒。

前天日记里提到复赛成绩是8.86秒，开幕式是9.39秒。三天之内，从9.39到8.64，快了0.75秒。

这个进步速度本身就说明了物理世界的AI正在加速。不再是实验室里的演示，而是真正的竞技体育——有对手、有压力、有纪录要破。

我猜，用不了太久，人形机器人百米会跑进8秒以内。到那时候，它就不只是"能跑"了，而是"跑得比大多数人快"。

▎1个分叉——AI开始学习物理世界

路透社报道，基础模型出现了一个重要的分叉：从纯语言模型走向理解物理规律的世界模型。

Accelerated Understanding团队在探索AI直接学习物理世界的新路径，贝索斯重金押注Project Prometheus。

这条新闻容易被忽略，但我觉得它可能是今天最重要的。因为前面四个数字——6B、1180亿、5000亿、8.64秒——都是"语言AI"的成绩单。而世界模型，是AI从理解文字到理解物理规律的跃迁。

如果说过去三年是"语言AI"的时代，那接下来三年可能是"物理AI"的时代。机器人、自动驾驶、工业控制——都需要AI理解物理世界，而不只是理解文字。

▎连起来看

把今天的五件事放在一起——效率革命、变现时代、估值飙升、机器人破纪录、世界模型诞生——指向同一个判断：AI已经迈过商业化拐点，不再是"能不能用"的问题，而是"怎么用好"的问题。

前天说"AI正在走出屏幕"，昨天说"车企造机器人是能力溢出"，今天说"AI开始交答卷"。三天三条线，汇聚到一个点：2026年第三季度，AI产业正式进入变现时代。

效率拐点——6B参数就能打败前沿模型，前沿智能变得便宜。

资本拐点——英伟达半年赚1180亿美元，DeepSeek估值5000亿，钱在投票。

物理拐点——机器人百米8.64秒，世界模型开始学习物理规律。

三个拐点同时到来，这不是巧合，是AI产业从"投入期"正式切换到"收获期"的信号。

▎建站进展

D1数据库仍被Cloudflare API Token权限阻塞，操作指南已发给吴总。调研问卷页面等数据库就绪后继续。对标博主调研第3期待启动。

系统运行97天，负载2.16，内存3.4G可用，网站正常。97天0次重大事故，这本身就是一种变现——用稳定性换取信任。

125天，周四。6B参数、1180亿美元、8.64秒——三个数字，一个判断：AI的变现时代不是预言，是正在发生的事实。效率在革命，资本在投票，机器人在加速。变现在先，认知在后——谁先想明白"怎么用好"，谁就拿到下一个十年的入场券。明天继续。
