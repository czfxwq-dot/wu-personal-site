    "行动困难"不是因为懒，而是因为你脑子里的"行动"门槛定得太高了

    文 / 半百观AI

    你一直觉得自己没行动——

    但有没有可能，是你对"行动"的定义错了？

    "行动困难"不是因为懒，而是因为你脑子里的"行动"门槛定得太高了？

    你觉得自己应该每天学两个小时AI，结果一次都没开始。但如果目标改成"每天打开AI对话工具问一个问题"，你可能第一周就做到了。

    问题不是你不行动——是你对"行动"的定义本身就排除了你自己。

    有一个叫斯蒂芬·盖斯的美国人，2012年的时候身材走形、生活颓废。他跟所有人一样，每年新年给自己定一个目标——"每天锻炼三十分钟"。跟所有人一样，每年都没坚持过第二周。

    后来他做了一个几乎不像决定的决定。他把"每天锻炼三十分钟"改成了"每天只做一个俯卧撑"。一个。就一个。多一个都不强制。

    他想的是，一个俯卧撑太简单了，任何人任何时候都能做，大脑连抗拒的理由都找不到。结果他一趴下去，心想反正都趴下来了，多做几个吧。那天他做了三十分钟。后来他把这个方法写成一本书，叫《微习惯》，畅销全球。

    盖斯做的事情其实只有一件：他重新定义了什么叫"锻炼"。原来在他的大脑里，"锻炼"等于三十分钟的有氧运动。这个定义之下，每天的情况都是"今天条件不满足，明天再说"。但他把"锻炼"重新定义为"做一个俯卧撑"之后——每一天都满足条件。每一天都是成功的一天。

    心理学家早在1908年就发现了一个规律，叫耶克斯-多德森定律。它的结论跟我们的直觉完全相反：对于困难的任务，你的动机越强、决心越大，你的行动效率反而越低。他们画出来的是一条倒U型曲线——动力太弱你不会动，这好理解。但动力太强你也不会动。因为当你的大脑接收到"每天锻炼三十分钟"或者"每天学两小时AI"这种指令的时候，它自动启动了一套评估程序：时间够不够、精力够不够、万一做不到怎么办。评估结果是"高成本、高风险"，于是大脑激活了回避模式。你拿起手机刷了四十分钟短视频。

    不是你懒。是你对"行动"的定义，在你什么都还没做之前，就已经把你的大脑吓退了。

    而"做一个俯卧撑"被大脑判定为零成本、零风险。放行。一旦你趴下去了，身体的惯性就接上了。盖斯改的不是标准，是定义本身。

    这个道理放在学AI这件事上，比你想象的还要直接。

    你现在用的华为鸿蒙手机里，内置了一个AI助手，叫小艺。你可能平时用它设过闹钟、问过天气，但它的能力远不止这些。今天只讲其中一个功能，叫"小艺任务"——这不是传统的语音指令，你说一句它做一下那种。小艺任务是AI驱动的自动化系统，它的逻辑就一句话：你用人话告诉它一条规则，AI自己理解你的意图，自动生成一条任务，之后条件满足时就帮你自动执行。

    比如你现在对着手机说："每天早上八点，播报今天的日程安排。"

    完了。就这一句话。AI自己解析出"每天早上八点"是触发条件、"播报日程"是执行动作。从明天早上开始，你每天睁开眼，手机会自动把你今天所有的会议、待办、提醒念出来。你不需要解锁手机，不需要找到日历App，不需要点进去翻看，不需要想起来去做这件事。你说了一次，之后AI每天都自己跑。

    这跟盖斯做俯卧撑是一回事。你之前的定义里，"学AI"等于"每天系统学两小时"。那个定义本身就把你挡在了门外。但你把它重新定义为"打开手机，对着它说一句话"——门槛消失了。你跨过去了。

    往下一层。你到家想连WiFi，出门想关WiFi省电，每天手动开关，麻烦但又不值得专门去折腾。你说一句："到家的时候自动开启WiFi，离开家的时候自动关闭WiFi。"AI理解"到家"是地点条件、"开启WiFi"是执行动作，自动生成一条规则。从此这件事从你的生活里彻底消失。

    再往下一层。你妈妈每个月等你充话费，你有时候忙忘了，月底她打电话催你，你又内疚又心烦。你说一句："每月1号上午十点，给妈妈充一百块钱话费。"AI自动解析出时间、对象、动作、金额，每个月到点自动执行。你再也不会忘记。

    你明天早上八点要出门，但天气不好说。你不用起床先查天气、再决定要不要打车、再打开打车软件——这个决策链条在你从醒过来到出门之间只有二十分钟，本来就很赶。你前一天晚上说一句："明天早上八点，如果下雨，帮我打车去公司。"AI到时间自动判断天气、自动帮你叫车。

    这些事情不是你学不会，不是你年纪大了记性不好，不是你跟新技术有隔阂。是你从来不知道你手机里这个AI已经可以这样用了。你一旦知道了，你试一次，它就变成了你的一种本能。而那个本能的起点，只是你重新定义了一件事——什么叫"开始用AI"。

    把"学AI"从"每天学两小时"改成"对着手机说一句话"。你的大脑这一次得到的就不再是"好难，算了吧"的回避信号，而是"我做到了"的正反馈。这个正反馈是你能持续往下走的唯一燃料。

    小艺任务能做的还有很多——来电时闪光灯提醒、充电完成语音播报、打开相机自动锁定屏幕旋转、退出视频App自动恢复旋转。你的生活里有多少事是你每次都要靠大脑去记、自己去做的？你可能从来没认真想过，因为你觉得"本来就是这样"。但本来不应该是这样。

    如果你想把小艺任务的全部功能彻底搞清楚——怎么创建、怎么管理、怎么删除、有多少种触发条件和执行动作可以自由组合——在评论区告诉我。我会专门写一篇完整教程，从头到尾掰开揉碎了讲。

    但在此之前，你先做一件事。就现在，拿起你的华为手机，对着它说第一句话。
