    2026-09-19

    📊 本周AI重大新闻

    1. Anthropic计划年底前建成5吉瓦算力

    Anthropic持续加码AI基础设施，计划年底前建成5GW算力。同时与OpenAI一道寻求20-30MW小型数据中心部署，算力竞赛进入"大小并举"的精细化阶段。

    来源：36氪

    2. Naive AI估值14亿美元，腾讯IDG等参投

    今年2月创立的大模型初创公司Naive AI完成三轮融资合计4亿美元，投后估值14.2亿美元，投资方包括腾讯、IDG资本、经纬创投及红杉，最早将于本月推出首款大语言模型。

    来源：36氪

    3. 黄仁勋：英伟达2027年芯片销量将翻倍

    英伟达CEO黄仁勋在苏格兰科技行业高管会议上表示，预计2027年芯片销量将是2026年的约两倍，同时强调AI安全至关重要，企业不应对安全性没信心的产品上市。

    来源：IT之家

    4. 诺和诺德联手Anthropic，AI制药进入新阶段

    诺和诺德宣布与Anthropic合作，将Claude引入药物研发流程，加速药物发现与开发效率。这是大型药企与AI大模型公司深度合作的又一标志性事件。

    来源：36氪

    5. 超七成受访者拒绝让AI完全控制电脑

    调查显示43%受访者明确拒绝AI访问电脑，另有27%持保留态度。安全顾虑成为AI Agent普及的关键障碍，提示词注入等攻击风险引发广泛关注。

    来源：IT之家

    🏭 智慧仓储货架动态

    1. 服贸会：AI物流装上"智能引擎"

    2026年服贸会展示最新智慧物流成果——仓储机器人自主爬架取货、无人配送车自主行驶送件。中国邮政广州中心日均处理邮件超700万件，AI智能管控系统实现堵包从十几次降至零次。

    来源：央视新闻

    2. 海柔创新HaiPick系统在日本BEAMS落地两年

    日本潮流零售品牌BEAMS分享海柔创新智能仓实战效果：57台ACR机器人、32500个库位，出库人力削减70%、仓储库容提升1.8倍，验证了箱式仓储机器人在零售行业的规模化落地能力。

    来源：凤凰网

    3. 广州首个攀爬机器人仓库投用，备战双十一

    广州首个新一代攀爬机器人仓库正式投入使用，将用于双十一物流保障。具身智能机器人开始走上分拣一线，独立完成晚8时到凌晨5时全夜班作业。

    来源：广州日报

    4. 海淀工匠杯：商业AI智慧分拣与仓储操作竞赛

    第六届"海淀工匠杯"设置"商业AI智能设备操作"和"商业AI智慧分拣与仓储操作"两大项目，将货架区域变为竞赛赛场，推动智慧仓储技能人才培养。

    来源：新京报

    📋 数字经济政策

    1. 上合组织数字经济论坛发布合作清单

    国家数据局主办的上合组织数字经济论坛在乌鲁木齐举行，发布《重点合作事项和意向清单（2026-2027）》，涵盖数字基础设施、农业、制造业、能源、交通物流等10余领域，形成近20项合作意向。

    来源：国家数据局

    2. 华为第五届数字经济发展论坛在上海举办

    华为全联接大会期间举办数字经济论坛，指出未来五年全球数智基础设施投资年均增速约19%，AI对全球经济累计贡献将超27万亿美元。

    来源：华为

    3. 香港发布首个经济社会发展五年规划

    香港特区政府公布《经济和社会发展第一个五年规划》，对接国家"十五五"规划，发挥"背靠祖国、联通世界"优势，积极融入数字经济国家战略。

    来源：香港数字政策办公室

    4. 工信部印发电子信息制造业十五五规划

    工信部与国家发改委联合印发电子信息制造业十五五规划，推动半导体自主可控。韩国媒体评价："以前的风险是没法向中国卖东西，以后是中国不用买韩国的东西了。"

    来源：虎嗅

    🔌 物联网传感器进展

    1. SENSOR CHINA 2026在上海举办，展示五大趋势

    全球三大传感器展之一SENSOR CHINA在上海普陀举办，600余家企业参展。核心趋势：AI深度融入传感硬件、多模态融合、端侧智能、人形机器人传感、产学研协同创新。

    来源：36氪

    2. 智能传感器与边缘计算深度融合

    2026年TinyML技术快速成熟，ARM Cortex-M55/M85集成Helium向量扩展，AI推理性能提升数倍。传感器正从"数据采集器"向"端侧智能感知节点"演进，实现本地数据处理和智能决策。

    来源：ISWS智能传感世界大会

    3. 江苏省发布物联网产业发展三年行动计划

    江苏省九部门联合印发行动计划，目标到2028年物联网终端连接数突破5亿，累计建设5G工厂超350个，推动"5G+工业互联网"向生产核心环节延伸。

    来源：江苏省工信厅

    4. 毕马威发布中国智能穿戴市场洞察报告

    报告指出Apple Watch Series 12搭载S11芯片性能大幅提升，新型皮肤气体传感器、钙钛矿太阳能驱动汗液生物传感器等前沿技术不断涌现，可穿戴传感器进入主动式AI助理新纪元。

    来源：毕马威
