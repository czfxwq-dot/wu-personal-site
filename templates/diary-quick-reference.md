# 观吾和山山日记 - 快速参考卡

## 📋 必须包含的部分

1. **📍 今日心绪** - 情感温度，1-3段
2. **🎯 今天的足迹**
   - 观吾的部分（思考/决策）
   - 山山的部分（执行/实现）
   - 我们一起完成的（协作成果）
3. **💭 遇到的困惑与思考** - 三个视角
4. **🌊 今天的感悟** - 核心洞察 + 细碎想法
5. **📊 今天的痕迹** - 量化记录
6. **🎁 今天的礼物** - 技术/心灵/关系三维度
7. **🌅 明天的期待** - 新尝试 + 挑战 + 应对
8. **✨ 今日一言** - 金句总结
9. **结尾信息** - 时间/地点/身体状态

## 🎨 写作要点

- ✅ 人文温度，不要技术报告
- ✅ 双语内容，重新表达不是翻译
- ✅ 协作视角，区分观吾和山山
- ✅ 叙事结构，有故事有反思
- ✅ 情感表达，有温度有深度

## 📁 文件位置

- 日记文件：`src/content/diaries/YYYY-MM-DD.md`
- 数据文件：`src/data/diaries.ts`（必须同步）
- 模板文件：`templates/diary-template-collaborative.md`
- 完整标准：`templates/diary-standards.md`

## ⚙️ 自动化要求

自动日记脚本必须：
- 保存到正确位置（content/diaries/）
- 使用 Markdown 格式
- 包含完整中英文内容
- 遵循协作格式
- 同步更新数据文件

## ✅ 质量检查

完成后检查：
- [ ] Frontmatter 完整
- [ ] 所有结构部分都有
- [ ] 观吾和山山分工清晰
- [ ] 有情感温度
- [ ] 中英文完整
- [ ] 数据文件已更新
- [ ] 构建测试通过
